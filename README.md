# Kestrel-1 rover

Firmware (C) and tools (Python) for the Kestrel-1 rover.

| Folder | What is in it |
|---|---|
| src/ | C firmware: motion commands and the ultrasonic range reader |
| tools/ | Python tools: the obstacle detector |
| data/ | Sample camera scores |
| results/ | Log of detector experiments |
| tests/ | Unit tests |

## Team rule

`main` holds only reviewed work. Start every new piece of work on its own branch.
